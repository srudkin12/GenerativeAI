# GitHub Pages Guide

The repository already contains a simple Jekyll/Markdown site in `/docs`.

After the repository has been pushed to GitHub:

1. Open the repository on GitHub.
2. Select **Settings**.
3. Select **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main**.
6. Select folder **/docs**.
7. Save.

GitHub Pages will use `docs/index.md` as the site entry page and `docs/_config.yml` for the basic site configuration.

## Why this arrangement

The repository remains readable as a normal GitHub project, while seminar participants can use a conventional web front end.

The site contains no server-side code and no research code.

## Before making Pages public

Run the Public Release Screening Checklist in `templates/public-release-screening-checklist.md`.
