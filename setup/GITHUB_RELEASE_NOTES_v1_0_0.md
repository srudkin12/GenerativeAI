# GitHub Release Notes — v1.0.0

## AI-Assisted Social Science Research: Methods, Governance and Reason Provenance

Version 1.0.0 is the first DOI-bearing public release of this research and educational resource.

The resource provides methods, worked examples and reusable templates for documenting and governing generative-AI-assisted social-science research, including proposal generation, verification, adversarial challenge, claim authorisation, reason provenance and manuscript governance.
