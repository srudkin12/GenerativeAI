# Public assets

Place only public-cleared images and diagrams in this directory.

Do not copy the internal seminar image directory wholesale.

Before adding an asset, check:

- whether it is original or third-party material;
- whether reproduction rights are clear;
- whether a reconstructed screenshot is labelled as reconstruction;
- whether a conversation image contains wording verified against the original record;
- whether the image reveals internal or confidential project information.
