# AI-Assisted Research Charter

**Project:**  
**Researcher / team:**  
**Date:**  
**Discipline / field:**  

## 1. Substantive research problem

What problem matters independently of generative AI?

## 2. Existing researcher contribution

What substantive knowledge, theory, prior method, data access or research programme already exists before AI assistance begins?

## 3. Analytical object

What exactly is being studied?

Include unit of analysis, relevant population/corpus/source base, time period, main constructs or outcomes and proposed inferential target.

## 4. Non-negotiable constraints

What should not be silently changed by AI-assisted exploration?

Consider inclusion/exclusion rules, aggregation decisions, required caveats, disciplinary distinctions, ethical/confidentiality rules and other project-specific constraints.

## 5. Permitted AI roles

- [ ] question generation
- [ ] candidate literature/search terms
- [ ] analytical alternatives
- [ ] code drafting
- [ ] qualitative coding suggestions
- [ ] robustness/challenge generation
- [ ] manuscript organisation
- [ ] prose revision
- [ ] other:

## 6. Verification boundary

For each permitted role, what must happen before the output can influence the evidence base or final claim?

## 7. Consequential decisions to record

Which decisions would materially change the research trajectory and therefore deserve a provenance record?

## 8. Escalation rule

When must the project return to substantive/analytical judgement rather than accept an AI-generated solution?
