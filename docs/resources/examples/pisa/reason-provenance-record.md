# Completed example — Reason-Provenance Record

**Project:** PISA moving-benchmark analysis  
**Record ID:** RP-Q-01  
**Stage:** Early question formation

## 1. Consequential research move

Formulate the question:

**Has the UK's relative position improved because its own performance improved, or because other education systems deteriorated more rapidly?**

## 2. Why it matters

The question changes the project from a conventional ranking comparison into an analysis that separates absolute performance change from movement within a changing comparison field.
