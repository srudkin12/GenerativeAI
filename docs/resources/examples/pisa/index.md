# Completed PISA resource examples

These pages show how the generic researcher resources can be completed using one documented research process.

The examples are drawn from the PISA project used elsewhere on this site. Their purpose is to make the **method of recording consequential research decisions** concrete.

They are not templates to copy mechanically. Another project may require different evidence, different inferential boundaries and different records.

## Evidential boundary

The examples use the mature project record and frozen evidence available for the PISA research process.

Where the record supports only a bounded attribution claim, the wording remains bounded. Retrospective reconstruction is not presented as contemporaneous evidence.
