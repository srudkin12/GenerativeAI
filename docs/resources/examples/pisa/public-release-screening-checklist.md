# Completed example — Public Release Screening Checklist

**Material:** Public PISA worked examples used in this resource  
**Purpose:** Demonstrate release decisions for research-process evidence

## Evidence status

- [x] Direct quotations are avoided unless verified against an authoritative source.
- [x] Reconstructed conversation wording is paraphrased rather than presented as verbatim quotation.
- [x] Current interpretation is distinguishable from contemporaneous evidence.
- [x] Empirical claims refer to frozen/verified project evidence.

## Confidentiality and permissions

- [x] Confidential peer-review material is excluded.
- [x] Private collaborator material is excluded unless suitable for public release.
- [x] Personal identifiers are not required for the examples.
- [x] Third-party imagery is not required for these resource records.
- [x] Journal/publisher confidentiality is not used as public process evidence.

## Research claims

- [x] PISA is presented as a worked illustration, not validation of the reason-provenance framework.
- [x] Generated code/text is not described as verified evidence merely because it was generated.
- [x] Methodological claims reflect the PCA/comparator evidence.
- [x] The B4→B9 direct-flow interpretation is not repeated as a valid inference.
- [x] Attribution claims remain bounded to the surviving evidence.
- [x] Retrospective claim-preservation records are not described as if formal contracts necessarily existed at the original decision time.

## Release decision

**Suitable for public release as a bounded worked example.**

Raw private conversations, confidential reviews and unreleased internal evidence dossiers remain outside the public resource.
