# Seminar, resource and workshop programme

The project now has three linked public-facing components.

## 1. Seminar — understand the architecture

The seminar gives participants the research story, contrasting PISA episodes, CAIS concepts for attribution ambiguity and reason provenance, manuscript governance through the Academic Writing Filter, and the ten-step practical protocol.

**Outcome:** I understand where generative AI can contribute and where governance is required.

## 2. Repository — repeat the method

The repository gives participants a 15-minute quick start, the ten-step protocol, worked cases, reusable decision/provenance/manuscript-governance templates, seminar follow-up material and workshop preparation.

**Outcome:** I can structure my own project using the same governance logic.

## 3. Workshops — practise the method

### Workshop 1 — Build the workflow
**Outcome:** I have specified my project and the roles AI may play.

### Workshop 2 — Challenge the research
**Outcome:** I have stress-tested one consequential claim and documented what survives.

### Workshop 3 — From evidence to manuscript
**Outcome:** I have an explicit claim boundary and a governed path from evidence to prose.

---

# Progression

**Understand → Apply → Challenge → Govern → Release**

The seminar should make the full approach intelligible.

The repository should make the method repeatable.

The workshops should make the method practised.
