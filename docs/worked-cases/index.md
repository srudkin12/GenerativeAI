# Seven worked cases

Each case uses the same structure:

**Research problem → consequential move → evidence → challenge → outcome → reason-provenance lesson → evidential boundary**

The cases are deliberately not presented as "success stories". Productive contribution, human governance, methodological challenge, AI-generated overinterpretation, claim narrowing and final-object inspection all appear in the same project.

2. [Human contribution as specification, constraint and refusal](02-human-governance.md)
3. [Generated analysis is not empirical evidence](03-code-is-not-evidence.md)
4. [When evidence makes the preferred method claim smaller](04-evidence-narrows-method-claim.md)
5. [A plausible number with an unwarranted inference](05-plausible-number-wrong-inference.md)
6. [Retrospective storytelling and the reason-provenance problem](06-retrospective-storytelling.md)
7. [Direct engagement with the finished scholarly object](07-finished-scholarly-object.md)
