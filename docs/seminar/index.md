# Seminar resources

The repository is being developed alongside the seminar:

**Generative AI in the Social Science Research Process: Illustrating Practice and Potential**

Department of Social Statistics, University of Manchester.

## Current release position

The working seminar deck is **not included** in this repository because the current version was prepared as an internal seminar object and has not yet passed a separate public-circulation review.

The public repository instead provides the practical research protocol, worked cases, reason-provenance material, manuscript-governance material and reusable templates that support follow-up use after the seminar.

## Possible later public release

A screened seminar release may add:

- a public PDF of the slides;
- a short reading guide;
- selected verified conversation evidence;
- public versions of project diagrams;
- a one-page reason-provenance / claim-preservation handout.

The repository should not silently publish internal seminar material merely because it exists in the project archive.
