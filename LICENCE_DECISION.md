# Licence Decision Before Public Release

No licence is imposed in this development starter.

Before the repository becomes public, select an explicit licence for the reusable text and templates. A permissive attribution licence such as **Creative Commons Attribution 4.0 International (CC BY 4.0)** is likely to fit the intended academic reuse model, but the choice should be made deliberately before release.

The release checklist should then be updated with:

1. the chosen licence;
2. a complete licence file;
3. matching licence metadata in the DOI deposit;
4. any separate rights statements required for third-party figures or reproduced material.

Do not assume that third-party images, screenshots, journal material, BBC material or other externally owned content inherits the repository licence.
